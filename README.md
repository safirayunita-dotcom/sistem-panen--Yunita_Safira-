# Sistem Pencatatan Hasil Panen

## Deskripsi
Sistem Pencatatan Hasil Panen merupakan program Python sederhana
yang digunakan untuk menghitung total hasil panen berdasarkan jumlah
hasil panen dan harga per kilogram. Program juga memiliki fitur
perhitungan diskon.

## Cara Menjalankan Program

1. Pastikan Python sudah terinstal.
2. Buka terminal pada folder proyek.
3. Jalankan perintah:

```bash
python panen.py
